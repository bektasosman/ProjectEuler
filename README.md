# Project Euler Solutions (Java)

Sammlung meiner Lösungen für die mathematischen und algorithmischen Probleme von [Project Euler](https://projecteuler.net/), implementiert in **Java**.

## Projektstruktur

- `src/main/java/org/example/` – Java-Implementierungen der einzelnen Aufgaben (`Aufgabe1.java`, `Aufgabe2.java`, ...)
- `src/main/resources/` – Eingabedateien für Aufgaben (z. B. `names.txt` für Aufgabe 22)

## Gelöste Aufgaben im Repository

| # | Aufgabe | Datei |
|---|---------|-------|
| 1 | Multiples of 3 or 5 | `Aufgabe1.java` |
| 2 | Even Fibonacci Numbers | `Aufgabe2.java` |
| 17 | Number Letter Counts | `Aufgabe17.java` |
| 18 | Maximum Path Sum I | `Aufgabe18.java` |
| 19 | Counting Sundays | `Aufgabe19.java` |
| 21 | Amicable Numbers | `Aufgabe21.java` |
| 22 | Names Scores | `Aufgabe22.java` |
| 23 | Non-Abundant Sums | `Aufgabe23.java` |

## Ausführen

Das Projekt nutzt **Maven**. Jede Aufgaben-Klasse besitzt eine eigene `main`-Methode und kann direkt über die IDE (z. B. IntelliJ IDEA) oder über Maven ausgeführt werden.
